# Dataset licenses and provenance

The project software license does not replace the terms attached to upstream
datasets. This file records the sources used to construct the committed CoRE
benchmark. Users remain responsible for complying with each upstream license
and citation requirement.

| Dataset | Upstream source | Upstream terms | Repository treatment | Release status |
|---|---|---|---|---|
| Chinook | [lerocha/chinook-database](https://github.com/lerocha/chinook-database) | [MIT License](https://github.com/lerocha/chinook-database/blob/master/LICENSE.md) | PostgreSQL source data is parsed and transformed into benchmark cases. Preserve the upstream copyright and license notice when redistributing substantial source-derived content. | Included with attribution |
| MONDIAL | [MONDIAL database](https://www.dbis.informatik.uni-goettingen.de/Mondial/) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) | Official PostgreSQL schema and rows are parsed; a local foreign-key file was transcribed from the upstream dependency diagram. Cite Wolfgang May's MONDIAL technical report and indicate local transformations. | Included with attribution |
| TPC-DS | [TPC-DS 4.0.0](https://www.tpc.org/tpc_documents_current_versions/current_specifications5.asp) | TPC [EULA and Fair Use policies](https://www.tpc.org/tpc_documents_current_versions/current_specifications5.asp) | The TPC tools archive and generated SF=1 `.dat` files are not distributed. Committed benchmark cases were derived from locally generated data. | Confirm derived-case redistribution before public release |
| Spider | [taoyds/spider](https://github.com/taoyds/spider) | No explicit dataset redistribution license was identified in the upstream repository during this audit. | Source SQLite databases are not committed; generated benchmark cases derived from them are committed. | Obtain or document redistribution permission before public release |
| Continuous benchmark | Generated by this project from the benchmark sources above | Inherits the relevant upstream dataset terms | Contains ordered sequences derived from the corresponding benchmark cases. | Follows source-dataset status |

## Local modifications

The benchmark generation process may select table subsets, normalize SQL data
types, export rows to CSV, infer or transcribe relationship metadata, construct
incoming tables, and generate expected proposals and database states. Detailed
commands and dataset-specific decisions are documented in `data/README.md` and
`data/Spider/README.md`.

## MONDIAL citation

The MONDIAL website recommends citing:

> Wolfgang May. *Information Extraction and Integration with Florid: The
> MONDIAL Case Study*. Technical Report 131, Universität Freiburg, 1999.

See the upstream MONDIAL terms-of-use page for the canonical BibTeX entry.

## TPC-DS preparation

Download TPC-DS Tools 4.0.0 directly from the official TPC specification page
after reviewing the applicable EULA and Fair Use policies. Do not commit the
downloaded archive, extracted toolkit, compiled binaries, or generated `.dat`
files. The expected archive used during benchmark preparation had SHA-256:

```text
d63e2bf093e23964b393364991be9fdd7a9cdd40fcdf91f99660eabde4c6162d
```

Verify this checksum after downloading and before extracting the archive.
